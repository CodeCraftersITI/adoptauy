# Claves públicas SSH

Una clave pública por integrante, con el nombre de su usuario Linux:
`camilo.pub`, `leandro.pub`, `inaki.pub` y `rodrigo.pub`.

Se generan en la PC de cada uno con `ssh-keygen -t ed25519 -C "<usuario>@adoptauy"`
y se copia acá solo el archivo `.pub`. **Nunca** la clave privada.
