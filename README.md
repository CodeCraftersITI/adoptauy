# AdoptaUY

Plataforma web de adopción responsable de perros y gatos en Montevideo. Proyecto final de la Tecnicatura en Redes y Software (ITI CETP-UTU) del equipo **CodeCrafters**: Camilo Blanco, Leandro Estévez, Iñaki Pérez y Rodrigo González.

- Stack: Laravel 13 (PHP 8.4), MySQL 8.4, Nginx y Docker Compose sobre Ubuntu Server 24.04.
- Entorno local: `infra/setup.sh` (ver `docs/contexto/infraestructura.md`).
- Requisitos, reglas de negocio y plan de pruebas: `docs/contexto/`.
- Flujo de trabajo: una rama por tarea de Trello, pull request hacia `main` con los RF que cubre, revisión de otro integrante y pruebas en verde.
